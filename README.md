# 📝 Список дел (Todo List)

Интерактивное веб-приложение для управления задачами на чистом HTML, CSS и JavaScript.

## Возможности

- Добавление новых задач (по кнопке или Enter)
- Отметка задач как выполненных
- Удаление задач
- Сохранение в localStorage
- Обновление списка без перезагрузки страницы
- Фильтры: Все / Активные / Выполненные
- Счётчик невыполненных задач
- Дата создания каждой задачи
- Кнопка «Очистить выполненные»
- Всплывающие уведомления
- Анимации появления и удаления
- Адаптивная вёрстка

## Стек

HTML5, CSS3, JavaScript (ES6+)

## Структура

todo-list/
├── index.html
├── style.css
├── script.js
└── README.md

## Запуск

Открыть index.html в браузере.
